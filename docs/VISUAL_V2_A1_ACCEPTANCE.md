# Visual V2-A.1：性情图谱与题签

日期：2026-10-11（Asia/Shanghai）。沿用 `codex/visual-v2-exploration` 与原worktree，起点 `eb028a59c70e8b735362335bf16d9941f88a5654`，更新现有 Draft PR #4。原V2-A的77张截图与研究资料保留，不用新截图改写历史结论。

## 实际完成

两套报告现在依次呈现：人物摘要 → 一句话结果 → 可选性情题签 → 多维度图谱 → 独立匹配示意 → 优势与留意之处 → 相似人物/文化 → 海报入口。揭晓页继续以立绘、姓名和称号为主体，未增加分数墙。

图谱默认共用5项固定synthetic数据：自主探索88、创造表达82、关系共鸣64、审慎规划46、稳健执行38。每项包含名称、0–100数值、条形刻度、两端倾向及简短解释；完整尺度说明可展开。数据顺序由displayOrder决定，不按分数排序。高分表示靠近右端倾向，不代表更优秀；不显示百分位、准确率或匹配概率。

| A · 入画寻己                                 | B · 风骨藏馆                                       |
| -------------------------------------------- | -------------------------------------------------- |
| 单列连续纸面、青绿细线、端点标记、右侧大数字 | 编号属性面板、金色分段刻度、数字上下分层、桌面双列 |
| 轻量墨线分隔，短解释自然接入长报告           | 深青独立底面与完整边框，保留档案属性感             |
| 朱砂侧线、横排两行古诗与作者作品             | 竖式短题签、金色诗句、下方横排归属/出处            |

B刻度的分段只是网格，填充宽度仍直接表示原始normalizedScore；99.5不会被画成100，0也不会被补成“最小一格”。A在0处保留基线端点标记，不意味着存在非零分值。两套不靠换色区分。

初轮390报告将分数推到首屏以外，已压缩重复长摘要、标题与说明占用。默认古诗版390×844首屏可见第一项数字和完整刻度；较窄/较矮视口允许正常滚动，不缩小正文。图谱位于题签之后，未藏在匹配解释或长文章末尾。

海报保留A 3:4、B 2:3画幅，只增加两个由dimensionId引用的标签（探索88/100、表达82/100）以及一行精简题句与归属。没有自动挑最高分逻辑。修正了原A 320px断点被通用人物卡高度覆盖、导致比例变长的问题，并加入五视口比例断言。未开发导出或保存。

## 只读结构与角色文案审计

- `features/report/result-atlas.ts`：独立只读ResultAtlasView/ResultDimensionView，字段包括dimensionId、label、normalizedScore、interpretation、scaleDescription、displayOrder、lowLabel/highLabel。prepareResultAtlas检查4–7项、有限0–100值、文本完整性、ID/顺序唯一性，返回排序副本。它不归一化、计算或静默截断，不是QuizPack验证器。
- `historical-atlas-fixture.ts`：固定演示和研究边界数据；没有导入题目、答案、权重或用户状态。
- `historical-visual-copy.ts`：只读人物文案DTO。匹配示意与海报均引用同一图谱维度ID，缺失引用不会补造分数。
- `temperament-inscription.ts`：古诗/原创判别联合，真实引用要求作者/作品/HTTPS来源/核对日期；原创不允许伪装为古人归属。结构检查不能代替实际出处核对或人工内容审核。
- `historical-inscriptions.ts`：同一人物原型的两组候选、相关维度和编辑意图。getStudyInscription只接收研究入口显式类型，不读取分数、答案、时钟或随机数。
- `theme/historical/visual-v2/result-atlas.tsx` 与 `inscription.tsx`：Server展示组件，没有评分副作用、远端检索或动态AI调用。

## 题签来源与适用范围

真实示例为李白《行路难·其一》末两句：“长风破浪会有时，直挂云帆济沧海。”已在[南通大学诗文正文](https://sxss.ntu.edu.cn/2018/0301/c6266a165818/page.htm)核对作者、篇名和两句原文；以正文为准，不复制现代鉴赏段落。[中央纪委国家监委诗文页](https://www.ccdi.gov.cn/toutiaon/201909/t20190930_95972.html)的检索片段交叉对应，直接正文抓取超时，不作为主证据。

原创候选为“借得松风开远意，且将星月作行囊。”页面明确显示原创拟古、非古诗引用和“QuizForge · AI草拟”；解读也说明没有动态匹配。该候选是本项目本轮草拟，文学质量与最终采用仍待人工审阅。B竖签缩短为“原创拟古”，完整“非古诗引用”保留在可见横排归属行，避免长竖排碰到分隔线。

两者都在李白原型候选配置下，分别关联探索/表达、探索/共鸣的编辑意图。本轮未设分数阈值、自动选诗、随机卡池或检索服务。报告的文化人物简介仍是原有待审槽位；古诗出处核实不意味着整份历史文化报告已经校订。
