# D1-B 历史人物答题演示：验收记录

## 范围与入口

- 演示入口：[未揭晓封面](/studies/historical/selected/cover) 的“开始演示答题”；实际路由为 `/studies/historical/selected/experience`。
- 演示含 12 道合成单选题，含一题长题干和超长选项。可选择、再次点击取消、返回修改、显示进度、阻止未选择时前进，并在结束前要求确认。
- 暂存只使用当前浏览器的 `localStorage`。`features/quiz/historical-demo.ts` 对版本、题目 ID、选项下标与时间戳进行校验；跨标签 `storage` 事件会显示冲突并暂停继续，损坏值不会被静默删除。
- 异常演示面板可显示保存失败、损坏书签与冲突副本。页面区分“已暂存”和“当前修改尚未保存”。
