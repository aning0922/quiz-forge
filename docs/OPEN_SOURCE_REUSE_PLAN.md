# 开源复用专项研究计划（D0.1）

本轮只建立研究任务，未完成候选仓库审计、许可证结论或技术选型，也未安装、移植或执行候选项目。以下是研究入口和需要核实的方向，不能当作当前能力或采用承诺。

## 时机与边界

在 D1 视觉验证期间完成独立评估，最迟在 D2 大规模引擎实现前形成可审阅结论。研究是单独里程碑，可与素材等待期交错，不阻断历史人物视觉预研；涉及后续实现需另行授权。若评估证据不足，保持现有架构并缩小下一步决策，不凭名称假定能力或许可。

不推翻 Next/TypeScript 模块化单体、QuizPack 纯数据、确定性结论、一次完成/锁定报告、受控组件注册和精品视觉。生产消费者不被候选项目的默认问卷 UI 或账号系统绑架；运营编辑工具不获得执行商品包代码或改分数的权威。

## 真实证据采集

1. 确认准确仓库、发行版本/commit SHA、包名、官方文档与仓库关联，识别同名或过时 fork；无法确认身份则标 unknown。
2. 读取目标版本 LICENSE/NOTICE 与关键依赖许可；核对商业使用、修改/分发、署名、copyleft、付费附属能力和素材许可。迁移代码必须保留要求的许可信息；无法确认则不集成，不假定“开源”自动允许所有用途。
3. 查询归档状态、最近提交/发行时间、近期 issue/PR 响应、维护者和版本发布节奏，记录查询日期与链接。不能只用 stars 或单次提交判断维护活跃。
4. 核实 Node 24、TypeScript strict、React 19.3、Next App Router、SSR/RSC 与移动端的兼容声明及实际试验；记录 ESM/CJS、peer 依赖、bundle/冷启动和安全边界。
5. 审阅实现中的表达式执行、动态代码、远程资源、外部函数、循环/复杂度边界及已知安全问题；评估能否限定为声明式、确定性且可审计。
6. 原始研究材料在忽略的 `.cache/research/`，不提交整库源码或未经授权素材。研究过程中只读取来源；需要运行的小实验另建隔离的自编夹具，明确批准的版本与依赖，不直接执行未审核来源脚本。

## 统一对照夹具

- 固定回答对应固定分数/原型；边界权重、缺答案、异常 ID、条件规则与平分策略。
- 原型/分支结果可达见证、状态保存/恢复、有限循环与超时；分布观察按商品目标，不强求平均。
- 同一 QuizPack 在纯运行器与独立商品布局中产生一致结论；候选不能取得 Key/事务权威。
- React 编辑配置往返、未知组件/props 拒绝、消费者 bundle 不包含后台编辑器。
- 升级候选版本后旧报告/剧情状态仍可读取；包格式转换损失与迁移成本明确。

这些是未来评估试验要求，D0.1 没有声称它们已运行。

## 决策与交付

每候选四选一：直接依赖、许可允许的模块移植、借鉴设计、不采用。逐项写证据、理由、模块边界、许可履行、性能/维护成本、版本固定与退出方案；没有足够证据可标“待定”，不得默认为直接依赖。

形成 `OPEN_SOURCE_REUSE_EVALUATION.md`（未来），包含查询日期、准确版本/链接、许可与维护证据、兼容实测、夹具结果、采用矩阵及未决风险。更新 ADR 与路线图，作者审阅后再决定实现。D0.1 仅提交本计划，不创建空的已完成评估报告。
