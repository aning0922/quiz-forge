1. A头部贴近副标题，人物向下移24px；署名压在衣袍后，移到有稳定底面的前景层。
2. A山水在标题附近偏浓，增加上方纸色遮罩；人物档案短句底面原来有硬边，改为全幅渐隐；桌面人物下摆透过短句底面的残影以人物容器裁切和静态渐隐收口。
3. B390首屏入口被底部截断，缩短移动舞台至340px；桌面短句裁切，改为内容自适应最小高度。
4. 缺背景显示破图符号，改为CSS背景，失败回到主题底色；缺人物保留尺寸并显示真实失败提示，不用Emoji或替代立绘。
5. 小型内容索引提升到12px，装饰英文字标仍9–10px，不承担信息阅读。

研发结论：A/B视觉身份可区分，标题与人物各有安全区，长报告可自然滚动；两方向主入口在390首屏可见，其他内容按自然流滚动。A更适合文化长卷阅读，B更适合角色收藏揭晓；成本/适用性是设计估计，见ART_DIRECTION比较表。作者尚未选定方向。
