# D1-A 历史人物视觉方向研究

日期：2026-10-11（Asia/Shanghai）。作者本轮明确授权 D1-A；本文件是研究方案与实现证据，**两个方向均待作者审阅，未冻结商业视觉**。

## 范围、交付与验收条件

只做首款《你的性格，历史上最像谁？》的两种高保真封面与人物档案构图，原创概念立绘/山水、字体、探索 Token、装饰组件和后续布局接口。人物档案为合成文案，没有输入、分数、匹配概率或真实用户结果。内部系列名“千载同心”亦属提案。

验收条件：两种方向结构可比较，390×844 真实构图，375/430/桌面截图和320宽边界检查，稳定长文阅读面，真实图片失败提示，减少动效静态等价，素材来源/许可明确，完整工程检查及分支同步。作者的风格/商业/人物审核独立于程序检查。D1-B/C、正式评分、数据库、AccessKey、AI后台、支付和发布不在范围。

## 两种方向

| 比较项             | A 东方人物志 / folio                                         | B 青金藏品卡 / cabinet                                 |
| ------------------ | ------------------------------------------------------------ | ------------------------------------------------------ |
| 封面构图           | 偏轴人物嵌入青绿山水长卷，左侧竖排短句、朱砂印章，横排大标题 | 中央深青收藏舞台，金线双层框、月轮、人物特写、竖排名签 |
| 冲击力（设计判断） | 山水、留白和人物衣纹形成文化气质，节奏舒缓                   | 深浅反差更直接，人物更像一件藏品，揭晓更强             |
| 阅读舒适度         | 暖宣纸从封面自然过渡到横排解读，长文易延展                   | 卡框只承载身份与人物；完整解读切换到浅色稳定阅读面     |
| 结果页             | 人物志：姓名、身份、短句、标签、分章解读、独立文化注解       | 收藏卡：人物封存舞台、卡面名签，再接独立长报告         |
| 成本（相对估计）   | 中：一套山水/人物可跨画幅；需控制山水浓度和人物裁切          | 中高：需要维护多画幅卡框、边距、人物焦点和深浅底面切换 |
| 可复用性           | 适合人物文化系列、卷册和叙事型商品                           | 适合小型人物收藏系列；不应强行套到所有主题             |
| 风险               | 人物缩得过小会削弱商品感；纸纹过强会影响阅读                 | 金色过量会显廉价；不能把正文/选项塞进舞台卡框          |

当前设计倾向：A 对文化叙事与后续长内容更自然；B 对结果收藏与封面人物冲击更有优势。这是研发判断，不是作者已选择方向。

## 代表人物统一设定

两方向共享同一张“李白”艺术化概念立绘，便于把差异归因于构图。采用成年中国男性、简洁发髻、短须、米白宽袖长袍、青绿内衫、窄腰带、竹卷，细笔设色结合水墨，服饰上有细小山水纹样。表情安定、略有自信，不取影视/游戏人物或现有角色参考。该形象不是历史复原，也没有证明历史人物真实人格。

原始生成图1024×1536 RGBA；网页导出800×1200 WebP，保留透明通道，概念阶段只一位人物，不扩角色库。双手和身体轮廓经可视检查，正式服饰年代、年龄、文化适用性和商用审核仍待人工。

后续角色生产规范：同样光向、色彩、描线密度和身头比例；头顶/衣袖/手部留8%裁切余量，中心焦点脸部约x48%/y13%；封面允许右偏裁切，人物档案不得遮住脸和双手；新增角色需要单独审批，不只改颜色。原始母版建议1200×1800以上，透明PNG，网页输出多分辨率WebP，单角色≤500KB。海报母版分辨率需D1-C验证后再定。

## 色彩、字体、材质与动效

- A：宣纸 `#F3EBDD`，墨 `#292D29`，青绿 `#36594D`，朱砂 `#963F32`，旧金 `#887044`。山水放人物舞台，阅读底面使用稳定纯色，避免把高频纹理铺到长文下。
- B：深青 `#142F2E`，米白 `#F3EBDD`，浅金 `#DFC28A`，次要文案 `#C4CCBC`。金线用于卡框和名签，正文回归墨色宣纸。月轮与云纹是原创程序装饰，不代替人物。
- 标题：Noto Serif SC 500/600，本地静态子集TTF，来源Google Fonts，保留SIL OFL 1.1。实际覆盖清单在 `public/assets/fonts/historical-serif-characters.txt`；本轮397个汉字/标点，新增文案必须重导子集。正文使用系统黑体栈，跨OS字形不同，跨设备嵌入正文黑体仍待后续决定。无浏览器端第三方字体请求。
- 标题采用宋体结构的横排，竖排只用于短诗、姓名和印章。长段≥16px、行高1.9左右；注解≥14px，小型辅助信息≥12px；品牌英文字标9–10px仅为装饰，不承载内容。
- 复用装饰：`Seal`、`ScrollRule`、`CloudOrnament`，与立绘文件分离；主题专属组件不进入通用UI目录。Token为实验CSS变量，不是正式资源Schema或注册表。
- 动效：只做一次320ms淡入/6px位移，入口hover160ms。没有循环粒子、逐字正文或自动音频。`prefers-reduced-motion: reduce`下移除入场和hover动画，静态构图、标签和链接完全可用。
