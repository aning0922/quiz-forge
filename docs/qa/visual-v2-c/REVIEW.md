## 发现与结论

本次没有发现阻断 Visual V2-C 研究边界的代码问题。

1. **预揭晓身份隔离：通过代码结构检查。** 封面和答题入口只引用中性展厅、题库与控制器；固定李白、题签、图谱和人物图只从 reveal、report、poster 页面入口导入。专项测试还检查封面/答题 HTML、已加载脚本正文和请求中不出现 `李白`、`li-bai`、人物肖像或结果路由请求。直接访问研究、揭晓、报告或海报仍是明确的 synthetic 研究预览，不代表答题已授权完成。
2. **不从答案评分或匹配：通过代码结构检查。** `CabinetPresentation` 只提供展厅文案、返回路由和揭晓路由；展厅索引由题目位置决定。`useVisualStudy` 维护答案、当前题号和交互状态；本机暂存仅包含版本、答案与更新时间，未导入权重、评分函数、人物匹配或结果存储。确认页明确固定合成展示不由十二题计算。
3. **本地存储隔离：通过代码结构检查。** C 使用 `cabinet-converged`，生成独立 `quizforge.visual-v2.cabinet-converged.v1` key；旧藏馆使用 `cabinet-exploration`。专项测试验证 C 写入不会创建旧 key，并覆盖恢复、冲突/损坏和保存失败状态。
4. **资源与授权：通过本地路径与 manifest 检查。** `CandidateImage` 的 asset 只接受封闭联合类型，产生固定 `/assets/themes/historical/visual-v2-c/` 路径；没有由答案、查询参数或外部 URL 指定的图片。room 有 480/960 候选，figure 有 160/480/960 候选；C manifest 回指 V2-B 和四厅源 manifest，比例缩放/重新 WebP 编码未产生新角色设定。资源仍为 `pending` / `not-approved`，不可声称商用获批。
5. **报告维度口径：报告自检通过。** `ConvergedReport` 只展示 `historicalAtlasFixture` 的五项图谱，匹配说明仅通过 `copy.matchNotes.dimensionIds` 显式引用 atlas。旧 `report.dimensions`（四项倾向）与 `report.rationale` 没有渲染，避免把旧四维文字与新五维数值混为同一计算结论。人物、优势、留意、相似人物和文化仍是固定 synthetic/editorial 文本。
6. **旧默认行为：存在需回归确认的风险，但当前不构成源码阻断。** `CabinetQuestions` 新增 optional `presentation` 并复用原 `useRouter`，默认缺省时仍使用旧 rooms、旧 storage namespace、旧返回链接和旧揭晓路由。最终完整旧V2交互、恢复和异常路径已随170通过/10既有跳过的全套生产回归执行；未以静态阅读代替回归。
7. **性能边界：已根据实测修正。** 初次DPR3诊断发现新候选会请求321,752B的旧1672w源；主代理随后将C上限收至960px，新增专项验证并复测DPR2/3均选77,708B源。原研究稿依然保留原图。20次生产采样、DPR诊断与高DPR专项已运行；其范围和实机限制见性能记录。
