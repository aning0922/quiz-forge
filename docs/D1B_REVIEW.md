## 已提出并要求修复的发现

1. 无障碍单选组曾只为每个按钮声明 `role="radio"`，其父 `<fieldset>` 未声明 `radiogroup`，并且方向键只移动焦点而不更新选择。现已改为带访问名称的 `radiogroup`，方向键会选择并聚焦目标；我在最终生产预览复核通过。
2. 初版 `storage` 监听只处理准确 storage key，忽略另一标签 `localStorage.clear()` 引发的 `key === null` 事件；这会让当前页面在外部清除后重新写入草稿。修订后以独立 `conflictLocked` 锁处理精确 key 和 clear event，双页面 E2E 验证多次修改后 key 仍为空；我在最终预览复核冲突提示与禁用继续操作通过。
3. 初版从冲突页“放弃并重新开始”未复位“已暂存”状态；且真实损坏书签加载后缺少页内丢弃/重置路径。现已复位暂存状态，并用独立损坏标记让保存失败后仍保留“丢弃损坏书签，重新开始”入口；我在最终预览复核该入口、重置和后续重新暂存通过。
4. 最初的冲突锁只拦截保存，仍允许用户前进到确认页；确认动作可删除另一标签刚写入的书签。现已在前进和确认按钮及 handler 同时实施锁定，新增双页面 E2E 在确认页写入外部书签后验证确认被禁用、外部值保留。损坏书签处于 `storageUnsafe` 时，确认只进入内存中的演示结束状态，不删除原坏值；明确的“丢弃损坏书签”操作才会清除它。
