已知公开内容包含开发机用户名/绝对来源路径、生成任务标识和普通 Git 作者身份。字体子集随附 OFL 许可；项目生成素材保留原始来源及 pending/not-approved 状态。仓库可见性改变不等于素材商用、内容、视觉或商品发布批准。

本检查不是绝对无泄漏保证：未逐图 OCR，未遍历 GitHub Issues、PR 附件或 Actions 日志，未核验服务器隐藏引用或独立 LFS 内容。后续继续禁止提交运行凭据、真实用户结果、访问 Key、私有数据库、依赖/构建/浏览器缓存；实际测试只用独立合成数据。
