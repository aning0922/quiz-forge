## 操作路径与交付

运营人员能顺着完成：商品 → 接收原包/验证归档 → 草稿及追加修订 → 固定修订预览 → 审核并封存内测版本 → 创建答题版本/发码。

流程导航只表示当前页面，不伪造完成状态；收到包不等于验证/归档成功，草稿不等于封存版本，内测版本不等于对外发布。

| 页面           | 本批行为                                                                                            |
| -------------- | --------------------------------------------------------------------------------------------------- |
| Studio 框架    | 桌面侧栏及主内容区，手机可操作的折叠导航、当前页指示；登录/不可用状态不冒充已认证                   |
| 商品列表       | 商品标题、类目、归档状态优先；紧凑搜索和状态筛选，扩展筛选可展开；保留分页、空态、失败、只读身份    |
| 创建商品       | 独立 `/studio/new-product` 页面，避免占用合法 productId 路由；原稳定 ID、提交和未知结果核实语义保持 |
| 商品详情/编辑  | 默认概览及流程入口，明确的页内展开编辑入口；表单保持挂载；归档恢复、冲突与核实紧邻对应操作          |
| 导入/验证      | 分别解释接收、待验证、失败、归档可用等事实，就近提供原有重读/核实/后续入口                          |
| 草稿/预览/版本 | 当前修订、不可变历史、固定预览及审核封存路径清楚；恢复区不依赖详情 GET 成功                         |
| 发码           | 版本选择、创建答题版本、发码/原请求核实、码状态及作废分区；私密下载仍用原通道                       |
| 技术信息       | ID/hash/实现 tuple 可展开；当前目标、状态、错误、待核实提示与关键动作默认可见                       |

## 展示合同与行为边界

1. 不新增数据库迁移、业务接口或状态机，不改评分/Key/会话/报告/权限/重放及资源读取协议。保留 flow/controller/storage/HTTP，实现集中于 Studio JSX、CSS 和路由组合。
2. 新导航不执行写操作，不自动提交/重试。成功来自原回执；未知状态保留原 tuple，不能因面板开关或列表刷新清除/重造请求。
3. 折叠仅控制展示，不条件卸载含表单、pending、authority 的子树。待核实、冲突、失权、错误恢复区默认可见，不藏入技术信息。更换 Product 仍按原身份隔离。
4. 保留 `InternalAuthorityProvider`、跨组件失权通知、`StableInternalWorkspace` 的挂载关系；商品详情读取失败不移除恢复。只读、归档、源资格仍限制写入。
5. 普通只读 hash/ID 可收纳；核实中的当前目标、修订、版本与结果必须在操作区可见，输入标签和错误说明完整。
6. 测试只适配有意改变的页面组织与选择器，不放宽 unknown/失权/资源清理/溢出/字号/触达断言。
7. 冻结的 theme preview/consumer renderer、字体、内容/展示 Schema 和描述文件不改。预览只调整 Studio 外框，内部六状态/PNG 保持。

补充预检约束：原包选择和接收组件持有原文件/原 key 的内存，不因展开卸载；unknown 禁止换文件。Key 页 controller 的 mount/dispose、页面隐藏撤权及私密复制/下载资格保持，清除仍要求原终结证据与明确勾选。workspace 当前未全面订阅跨标签失权，不能将其他页面的该能力泛化为已经具备的全局事实。

## 主控共享展示接口

`src/features/studio/presentation/` 由 root 单写，均无 fetch、写操作或业务状态：

- `StudioWorkflowNav({ productId, current, previewHref? })`：current 为 product/imports/draft/preview/versions/keys；只标记当前页面。无固定修订预览链接时回草稿并明示先选修订。
- `TechnicalDetails({ children, label? })`：原生 details/summary，children 始终挂载；只放支持信息，不包住恢复操作。
- `StudioPageHeader({ title, description?, actions? })`：统一标题与操作区，各页可独立布局。

URL 使用已有 helper 或编码后的 productId；导航不推断授权。不新增无实现按钮、假统计、假进度和批量操作。
