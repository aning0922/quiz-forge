## 已完成的数据边界

`src/features/report/seven-desire-fixture.ts` 是本闸门唯一公用来源。固定原创角色维璃／镜曜执冠者／pride，宣言为原创角色台词；故事明确是幻想内容，不能当作参与者经历、命运或心理判断。七维依次为 pride、envy、wrath、sloth、greed、gluttony、lust，固定展示值 88/54/66/38/79/61/72；各项是独立 0–100 刻度，不合计为 100，不是概率，不评善恶、健康或能力。Lust 的消费者标签为“心动与亲密”，解释保留色欲的幻想象征并避免露骨内容。

topDimensionIds 的 pride/greed/lust 是固定编辑引用，不是新排序、匹配或最高分算法；改变分数不会改变角色或引用。traits、relationships、tensions、strengths、imbalances、characterStory 只用于展示。SevenDesireDimensionId 是内部显示词汇；readonly 是编译期约束，不代表正式不可变快照或运行时冻结。

七个 `sevenDesireQuestions` 只有 id/title/options，无权重、分数、答案解释、匹配规则或真实题库声明。七个情境包含一题长题干与长选项，只服务首闸门版式及代表交互研究，不能视为完整测评效度或完整答题流程已经实现。

`prepareSevenDesireStudy` 调用既有 `prepareResultAtlas`、`referencedDimensions`，只检查合成来源、身份/声明、恰好七个已知且顺序完整的维度、三个唯一且可解析的编辑引用及必要叙事字段。异常直接拒绝，不夹值、取整、补零、替换人物或计算结果。DTO 不接受素材 URL、代码字段或可执行内容；文字由正常 React 文本展示，不应交给 HTML 注入或动态执行。这个 guard 不是不可信包导入器；它没有 ZIP、未知字段拒绝或正式 Schema 安全验证能力。

## 恢复与冲突的后续要求（本次未实施）

作者选择视觉方向后，按本轮 D1-D 原授权实施恢复时，需独立产品/研究命名空间及版本，不能写入 `quizforge.d1b.historical-demo.v1` 或任何 `quizforge.visual-v2.*.v1` 已有空间。version 必须对应题 ID/选项语义；不能只改 key 后沿用历史 12 题 parser。恢复时逐条校验已知 ID、选项整数范围、时间和允许字段，拒绝损坏/未知版本并提供显式重置；无结果身份、分数、美术引用存入答题进度。

当前历史控制器监听相同 storageArea 的本 key 或 key=null（其他标签 clear）后锁住编辑，避免静默覆盖。keepLocal 仅解锁并保留本机内存，下一次保存才覆盖，不是合并或服务器冲突解决；corrupt 状态阻止 save，reset 删除 key 后才解除。七题后续需明确保留本地/读取另一标签/重置的含义，以及冲突期间确认、返回、重载、保存失败和监听清理。第一闸门代表页面未因此获得持久化、跨设备或正式完成权威。
