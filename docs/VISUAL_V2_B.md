# Visual V2-B：结果主视觉与美术表现研究

日期：2026-10-11（Asia/Shanghai）。本轮在 `codex/visual-v2-exploration` 的 Visual V2-A.1 提交 `f33594b0b6cea4f0fb99013cfd33b9a55cd02393` 上继续，只新增独立研究路由 `/studies/visual-v2-b`。V2-A / A.1 的页面、截图、图谱 DTO、题签 DTO 和未来评分契约均保留；本文件不冻结最终商业视觉或正式 QuizPack Schema。

## 为什么旧版仍显得单薄

外部商业审查指出的问题不是功能缺口。V2-A / A.1 的 A、B 均以相同的中性透明人物 PNG 为核心：人物与背景没有共同光源、前景或场景关系；揭晓页的圆形/框线结构把人物压成信息面板的一部分；报告主视觉只保留约 90px 的贴图；同权级的标题、说明、题签、图谱和框线竞争注意力；海报沿用网页卡片的层次与操作语境。因此，诗词和属性虽可读，却没有参与构图叙事，人物也难以在前三秒建立情绪记忆。

本轮以完整画面替换“孤立贴图 + UI 容器”的主视觉假设：图像先承担人物、光线、场景和留白，React/CSS 只放入可变的人名、称号、题签、固定合成说明与准确图谱。该做法仍是研究原型，不代表两幅艺术源图已经获得作者认可或商业批准。

## 动效与可用性设计

图片成功加载后只进行一次 650ms 的透明度淡入，既不阻止用户进入报告，也没有逐题等待、循环动画、位移或自动切换。加载期通过可见状态文本说明“画作正在展开”，失败时保留人物题名和报告阅读路径并明确说明图像未呈现。`prefers-reduced-motion: reduce` 下动画和过渡均取消，内容不会被移除。

主视觉以 2:3 原画完整 `contain` 显示，避免裁切脸、手和衣摆；生成时也为标题、称号与两行诗预留了静区。海报并非固定 3:4 或 2:3 成品：原画完整保留，caption 会随动态称号、题签和标签自然向下延伸，因此最终画幅可比原画更长。报告在主画之后引入同方向的无人物章首画：A 以晨雾把深青山河消入暖纸，B 以暗绢、月河纹延续图鉴材质，再进入一句话结果和安静图谱；背景画不铺在横条底下，数值阅读区保持干净。图片成功加载后的单次淡入、缺图可读 fallback 和 reduced motion 关闭动效均已实际验证；A 的缺图/加载状态将暖白姓名去光晕并与右侧状态文案分离，计算对比度断言不低于 4.5。

## 风险、未完成与停止条件

最终视觉复核显示，两套方向均已解决旧版“人物 PNG + 卡框 + 标签”的首屏问题：A 的行旅情境更完整，B 的脸部、持杯与月轮在手机上建立了更强的第一眼焦点。A 的晨雾过渡消除了主画到阅读区的硬切，B 的暗绢月纹使图鉴材质延续到章节入口；A 的缺图状态也已使姓名与状态信息分离并保持可读。此轮限定的“主视觉与性情图谱衔接区域”没有视觉阻断。

完整长报告仍通过链接复用 V2-A.1，未在本轮进行美术重做；因此不应声称图谱之后的匹配依据、优势与留意之处、相似人物与文化章节获得了同等级的美术升级。

建议作者优先评审 **B「风骨映月」** 作为结果揭晓与收藏画作方向：这来自人物距离、眼神、持杯动作与月轮明暗对比共同带来的角色吸引力，并非只因金色或深色装饰。A 应保留为文化叙事更自然的候选。两图的年龄观感、镜头距离和性格姿态不同，不应未经下一轮美术统一就混作同一正式资产体系。

此轮尚未完成作者审美评审、真机 iOS/Android 检查、完整读屏流程、弱网性能测量、商业授权或史实内容审核。原画显示虽避免了移动裁切，却比旧透明 PNG 增加首屏传输成本；应在获准保留的方向上再做真实设备加载与性能预算。图谱的数值语义、题签出处、未来确定性评分/快照约束继续服从 [Visual V2-A.1 展示与未来评分契约](VISUAL_V2_A1_CONTRACT.md)，本轮没有改变它。
