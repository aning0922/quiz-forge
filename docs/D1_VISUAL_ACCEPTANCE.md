# D1 视觉验证标准（原阶段标准与历史记录）

视觉质量标准继续有效，任务授权及验证范围遵循 [AGENTS.md](../AGENTS.md)。下述 D1 分期、十五状态和原授权只描述该阶段，不要求文案或局部 UI 修复重拍三主题全矩阵；仅检查本次受影响的页面、状态及断点，已有未变化截图与结论复用。其他主题未开发或未经批准不阻断当前局部交付。

## 范围与退出条件

D1 只验证三商品主题系统及完整五状态，用确定标记的合成题目/结果。不会顺带实现正式评分、数据库、AI 后台或渠道交易。D0 已定义标准；D1-A/A.1 证据保留，本轮作者授权 D1-B 封面/答题/本地暂存恢复演示。完整五状态与其余主题仍需后续明确授权。十五状态不是十五张相同布局换色图。

补充指令保持这十五个必验状态。结果展示同时验证简版结果和可滚动的详细报告；若商品采用独立报告页，增加该布局截图。配方与专属组件允许商品级定制，D1 先验证合同及代表布局，不提前实现 QuizPack 导入器。正式组件注册表、Schema、构建/验证/导入工具在 D1 之后落地。

每主题以至少一个经审核的代表角色和相应背景/装饰形成完整视觉身份。角色原型数量未定时不扩展整套角色库。缺角色、字体授权或关键背景的主题不能宣称正式视觉通过；可提交标明 pending 的研究稿供反馈。

## 规格

- 设计基准 390×844；截图至少覆盖 375×812、390×844、430×932、桌面 1440×1000；320 宽做最低可读/无溢出验证。
- 三主题各有 cover/question/resume/result/poster 配方 ID；清楚说明结构、装饰层、内容层与固定操作区，不把布局配置限制在颜色、圆角。
- 色彩与字体以 `VISUAL_SYSTEM.md` 为简报。选定跨设备中文字体后明确许可证、子集、加载后回退；题目正文 ≥16 px、行高 ≥1.5，信息最小文字原则上 ≥12 px。
- 所有主要操作目标 ≥44×44 px，键盘焦点可见，选项选中状态同时有形状/文字反馈；错误由文字说明，非颜色单独表达。
- 普通文字对比度 ≥4.5:1，大文字与交互边界 ≥3:1；记录实测关键组合，装饰层不影响阅读面。
- 尊重 reduced-motion；常态动效按三主题时长设计，每个重要反馈有静态等价；无闪烁、自动循环干扰阅读或阻塞按钮。
- iOS Safari 与 Android Chrome 实机/可用环境需验收：安全区、地址栏变化、字体、滚动、长文和海报保存流程。Playwright Chromium 是 D0 工具烟测，不能冒充 Safari 实机通过。

## 素材清单与制作顺序

先读各主题 `asset-plan.json`：代表角色 → 场景背景/纹理 → 装饰 → 字体 → 卡边/海报。所有文件保持主题比例、线条、光照一致，禁止随意拼接现成素材。透明角色保留完整轮廓和裁切安全区；文本由程序排版，图片不带伪中文。

素材每项从 pending → review → approved；记录生成/委托来源与商用授权依据，作者验收风格和角色适用性。D0 清单中 `licenseEvidence=null`，因此没有已批准资源包。

## 浏览器验收流程

1. 准备统一的短文/长文、单题/多题、可选/已选、恢复/冲突、长报告与海报合成夹具，所有示例显著标注演示。
2. 根据本批改动选择代表页面、状态及断点，实际浏览器查看并保存必要截图；使用生产构建的 E2E 遵守现有专属环境要求。截图注明主题、状态、视口和浏览器。完整三主题交付才验收十五状态，不重拍未变化画面；一般改图由一名负责人查看，独审只看风险相关代表图。
3. 检查实际点击、选项反馈、滚动、焦点、加载、缺素材、导出中/失败状态。图片未加载时保留布局并提示，不出现低质量角色占位。
4. 动效变化时检查 reduced-motion；排版/响应式变化时检查相关长文、320 宽、字号放大或 safe-area。未影响这些行为时复用已有结果，不一律重跑。
5. 海报检查真实导出图尺寸、裁切、字体无缺字、透明合成、保存可用与信息脱敏；不能以网页截图按钮假称可保存。
6. 素材、加载或动效变化可能影响性能时，记录对应预算、设备条件及必要观察，不为普通文案修改新增性能采样。报告真实性优先于虚构性能分数。
7. 在已有验收或 PR 中记录通过/未通过、复用证据和限制，不增设管理文件。满足本批条件即收口；需要作者视觉、内容或素材批准的部分单独提交，不重开已批准且未变的基线。

## 阻断项

本批承诺交付中的正式角色被占位物替代、必要状态缺失、正文遮挡、海报泄露 Key、缺必要授权、七宗罪缺非诊断说明、移动溢出或关键操作不可达均为阻断，不能由编译或检查数量抵消。代表性查看及风险所需证据完成即可，不把未授权主题、固定截图数量或轻微非阻断排版细节扩成新门槛。
