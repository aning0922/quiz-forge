# F1 测评与资源版本底座

2026-10-11（Asia/Shanghai）。状态：实现与本地回归完成，独立审查无剩余 P1/P2，Draft PR/CI 收口中。先完成本文与关联架构/数据/资源/路线文档，再写生产目录中的底座代码。当前只交付局部运行时合同，后续业务不能据此声称已实现。

## 范围

1. 一款测评对应现有 Product 稳定身份，主类目与标签独立于引擎和视觉；不新增重复的 QuizProject。
2. 运行时结构合同涵盖测评、草稿、资源清单、有限内容/结果/报告/布局引用；从同一合同推导 TypeScript 与 JSON Schema。未知字段、非法数值、数量/长度超限要拒绝，不能静默丢弃危险字段。
3. 资源默认归本测评；校验目标 productId、题/选项/维度/结果/资源引用、重复标识、路径及固定版本。声明的授权/哈希是待核验数据，不代表已检查文件字节或真实批准。
4. 草稿 revision 乐观更新和内容哈希纯逻辑：冲突拒绝；实际内容变化才产生新 revision/hash，旧对象不变；省略content或canonical内容相同为no-op，返回独立副本并保留revision/hash/证据。审核证据绑定product/draft/revision/hash，实际内容改动后失效。没有数据库并发权威或发布接口。
5. 一个独立 synthetic 历史人物参考包，至少三个结果、每个结果的声明见证答案、完整基线槽位和资源描述。它不接入消费者研究页，不计算评分，不声称见证经引擎执行或文化/素材商业审核。
6. JSON 校验命令和结构化错误、生成/校验 JSON Schema 的入口。输出结构/归属/引用结果，并显式报告发布不可用及 ZIP、文件字节、评分、注册表、人工审批未验证。

## 实现边界

固定 `zod@4.6.5` 为结构合同依赖，使用 strict object、有限容器与 `z.toJSONSchema`，TypeScript 类型由合同推导。依据 [Zod API](https://zod.dev/api) 与 [JSON Schema 转换](https://zod.dev/json-schema)；交叉引用/归属检查独立执行，不声称可全部表达为 JSON Schema。合同版本为 `foundation.v1`，禁止把它包装成已冻结的完整 QuizPack v1。

不新增数据库/迁移、管理 UI、网络写 API、ZIP 解析、评分器、AI、真实素材或 Key。原合成视觉与 PNG 导出原样回归，已有素材 approval 状态不变。路线 P1 才实现 ZIP/构建安全能力，P2 才开始数据库和认证工作区。

## 验收矩阵

| 交付     | 必须通过                                                   | 不代表                   |
| -------- | ---------------------------------------------------------- | ------------------------ |
| 结构合同 | 合法样例；未知/执行字段、非有限数、空白/超限值拒绝         | 输入内容真实或安全可发布 |
| 归属     | 两份独立测评夹具；跨 product/版本资源与题目引用拒绝        | 数据库租户权限已实现     |
| 引用     | 重复ID、无效option/维度/人物/素材/模板引用、缺必需槽位拒绝 | 组件在运行器存在         |
| 路径     | traversal/绝对/反斜线/未知类型、重复冲突路径拒绝           | ZIP条目和文件魔数已检查  |
| 草稿     | revision冲突、内容hash确定性、旧对象不变、审核证据失效     | 实际持久化/发布事务      |
| 参考包   | 三结果和声明见证结构合法；pending可预览但不可发布          | 正式题库或匹配引擎       |
| 工具     | 正常退出、错误非零、大小/深度边界、无敏感输入回显          | 上传接口或完整导入器     |
| 回归     | format/lint/typecheck/test/build/E2E，生产3100独占         | 作者视觉/素材/商业批准   |
