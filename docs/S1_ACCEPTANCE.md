### 一次确定的展示规则

- 共享的是状态解释和导航建议；列表、工作台、详情分别排版，不再把完整 `OperationsSummary` 塞进每一条记录。
- 一个区域一个主操作：无草稿→内容处理；当前草稿缺精确审核→核对当前修订；有审核无固定版→审核与版本；有当前固定版→内测记录。归档或事实不明时使用查看/核实入口。所有动作仅导航，原服务仍重新授权，不能直接从摘要发写请求。
- 当前修订与历史版本分别表达。预览只表示入口，不代表已人工体验；历史试玩不授予新草稿内测资格。接收、检查状态来源不同要显式说明。
- 封面/简介、四项虚拟指标、全局发码/参与量、业务备注、任意阶段排序、在线编辑器不补假数据。已有三项指标、最近创建、单测评记录仍保持原稿布局和主次。
- 原稿 11–14px 字号和 30–36px 按钮做必要可访问性适配：正文 ≥16px、操作 ≥44px，通过减少重复信息和留白控制密度；不能靠缩字实现还原。
- 正常证据可展开，UNKNOWN/CAS/失权/当前原请求身份与恢复不能默认折叠。表单和 File 保持原 owner/作用域，摘要刷新不换基线、不清原文件、不重设固定预览。
