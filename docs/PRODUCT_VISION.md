# 产品愿景

## 定位

QuizForge 是趣味测评商品研发、导入与运营平台。核心定位调整为 **Codex 精品商品研发 + QuizPack 标准化导入 + QuizForge 统一运行与运营**。每款商品先推敲题目、评分与专属视觉，再形成带版本的标准包，验证、预览、人工审核后发布。未来批量能力建立在成熟规范上，不以后台输入一句话直接上线作为首版主模式。

商品的价值闭环：有世界观的封面 → 易读、沉浸的答题 → 值得收藏的结果 → 可保存的分享海报。程序保持评分可复现，作者负责内容及视觉验收。后台主要负责 QuizPack 导入/验证、商品与版本、题库和结果查看/编辑、素材管理、完整预览、审核发布、Key 批量生成/导出、已发布管理和访问/完成率统计。后台 AI 生成/编辑是未来辅助能力，关闭 AI 不阻断普通商品运行和发布。

## 商品研发与报告策略

Codex 可在独立商品工作区研发与测试数据包；普通测评依靠已注册引擎/配方导入即可运行，无需改业务代码。精品布局可在主项目开发经过审核的 React 组件，由包引用固定注册 ID/版本，而不能执行包内代码。逻辑与视觉可分别版本化，同一逻辑支持不同视觉版本与报告模板。

报告可采用固定模板 DETERMINISTIC、预设模块组合 COMPOSED 或可选 AI_ENHANCED。三模式结论全部确定性；AI 仅在确定结果后增强文案，失败使用完整基线，最终持久化并重复读取。规范见 `QUIZPACK_SPEC.md` 与 `REPORT_MODES.md`。

## 访问与商品规则（需求，未实现）

- 公共目录允许浏览已发布商品介绍；未购买用户仅可查看介绍和明确授权演示。正式答题必须持有对应商品有效 AccessKey。
- 普通买家不强制注册；消费者与后台分别布局和权限。未来可主动证明持有多个 Key 后关联个人账号，但不是首版依赖。

- 唯一 Key 是访问凭证，每个 Key 最多正式完成一次。中途保存与恢复不消耗正式完成次数。
- 正式提交后，原链接可重复访问锁定结果，不可重新评分、重开或通过清理浏览器重测。
- 结果绑定已发布内容、评分、主题、模板及素材版本；新版本不改变已完成用户结果。
- Key 初次激活固定版本；商品更新不改变进行中的答题。Key 的到期、撤销、退款和结果保留策略在经营阶段另行确认。
- 原链接有凭证能力，禁止公开传播。分享海报不包含 Key 或答题链接；未来分享链接需独立、可撤销、只读授权。

## D0 成功条件

工程可运行；模块及模型边界明确；三主题的完整五状态有设计计划；本地检查、生产构建和浏览器烟测通过；文档准确区分计划与实装；独立提交并同步。D0 不以图片数量、问卷功能数量或商业收益衡量成功。

## 商业前置条件

小红书经营类目和外部 H5 履约权限尚未确认。不得假设已获商品经营、支付、订单 API 权限。不开发平台强耦合交易流程，不自动发布商品，不承诺收入。第三方接入前确认平台协议、合法销售品类、数据处理边界与履约渠道。

## 非 D0 范围

真实数据库、评分实现、AI 生成、运营后台、支付订单、自动发货、生产部署、最终角色立绘、完整十五状态 UI。它们均为后续规划，需逐阶段授权和验收。
