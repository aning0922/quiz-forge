# 视觉系统

## 五层架构

根据 D0 补充要求，正式分层升级为下表。原定 Design Tokens、Theme Asset Packs、Page Layout Recipes、Result Templates、Poster Templates 继续作为实现载体；它们不限制商品专属页面和交互。

| 正式层级           | 共享能力与商品定制边界                                                       |
| ------------------ | ---------------------------------------------------------------------------- |
| 1 全局设计基础     | 响应式、阅读与触达、无障碍、安全区、性能；业务提交/恢复/报告合同共享         |
| 2 Theme System     | 古风/卡通/二次元/暗黑的设计语言：Token、纹理、组件、字体和动画规范           |
| 3 商品独立视觉资源 | 各商品自己的角色、背景、图标、装饰、可选音效；允许复用已审核素材包，独立版本 |
| 4 商品专属布局     | 封面、答题、恢复、结果、详细报告、海报可深度定制，不能强制同一 DOM 换色      |
| 5 商品交互表现     | 不同进度、选择反馈、转场与揭晓；可信配方和专属组件实现，保持业务一致         |

## 商品视觉与组件注册（规划）

同一 QuizVersion 可绑定多个 ProductVisualVersion；商品发布版本选择具体主题、独立资源包、布局、交互和报告模板。素材和题目/评分数据解耦，资源复用通过不可变包 ID/版本/哈希，不按当前最新路径读取。

精品商品可由 Codex 在主项目开发 React 布局（未来路径 `features/theme/product-layouts/<product>/`）。审核后登记 registryId、componentVersion、props Schema、兼容引擎/状态和最低应用版本。包通过受控 ID 引用，未知组件阻断导入；不执行 QuizPack 内 JS/React，不从远程 URL 加载组件。

专属组件使用只读 DTO 与受控交互回调，不直接消费 Key、改分数或生成 AI 结论。组件版本和报告模板随 ProductVersion 固定，应用升级/回滚必须保留历史兼容；旧报告不能被新组件无意改版。

商品音效是可选表现层：合法商用、用户触发、默认不自动播放、可静音，不承担唯一反馈。D0 不添加音频或音效系统。

## 实现载体

| 层                  | 责任                                               | 版本与边界                                                |
| ------------------- | -------------------------------------------------- | --------------------------------------------------------- |
| Design Tokens       | 色彩、文字层级、空间、描边、形状、阴影、动效、层级 | 基础可访问性合同 + 主题语义 Token；不能仅靠换颜色表达主题 |
| Theme Asset Packs   | 角色、背景、纹理、装饰、字体及其授权               | 版本化 manifest；与 React 组件分离；资源哈希与审核状态    |
| Page Layout Recipes | 封面、答题、恢复的构图/阅读/交互配置               | 从可信组件注册表组合；每主题可有不同布局结构              |
| Result Templates    | 收藏型角色档案、倾向图、说明和分享入口             | 接受锁定报告 DTO，不计算分数；主题与报告模板版本固定      |
| Poster Templates    | 专为导出设计的静态画幅、裁切、排版、署名           | 独立于网页截图；字体加载、像素密度、权限与脱敏都需验证    |

D0 实装只有工程壳层 Token、三主题方向简报与装饰研究。`src/features/theme/catalog.ts` 的 `status=direction-only` 不是正式 ThemeDefinition。正式 Token Schema、素材发布校验、配方注册表、结果和海报渲染均待后续阶段。

## 基础与主题 Token

基础约束拟议：正文可读、44 px 触达、清晰焦点、对比度、纵向阅读、安全区、减少动态效果。主题语义如 `surface.reading`、`ink.primary`、`ornament.seal`、`type.display`、`motion.selection` 映射到不同视觉语言。具体 token 名称在 D1 验证后固定，避免现在冻结未经浏览器审验的完整风格。

后台未来可使用 shadcn/ui 基础组件；面向用户的封面、结果和海报必须使用主题构图与素材。通用 Button 提供触达/焦点，不决定商品视觉身份。

## 三主题设计策略（D1 目标）

### 历史人物匹配：新中式古风

- 构图：纵向卷轴层次，偏轴人物与大留白；正文横排，短标题可竖排；印章为视觉落点，不在文字下面叠加纹样。
- 色彩：宣纸 `#F3EBDD`、墨色 `#292D29`、朱砂 `#A33F32`、青绿 `#47665A`。纹理降低对比度干扰，所有正文在稳定阅读底面。
- 字体：授权宋体用于标题，正文用可读黑体；文化注解独立层级。D0 系统宋体仅参考，不是跨设备最终字体。
- 素材：原创古代人物（身份/姿态一致）、宣纸底纹、卷轴边缘、印章、古典纹样；不得挪用电视剧/游戏/商业插画人物。
- 动画：开篇淡入/卷页暗示 250–400 ms；选项反馈 120–180 ms；不连续滚动人物、不做逐字正文动画。
- 结果方向：可收藏的人物档案长卷，角色名称、原型解释、性格侧写、文化注解明确区分；海报采用单幅人物及短句。

### 七宗罪趣味人格：暗黑二次元幻想

- 构图：中央纹章与原创幻想人物舞台，属性刻度分布两侧；答题正文回到稳定阅读面，结果角色卡与多维图分层。
- 色彩：夜幕 `#181522`、月白 `#EEE7FA`、紫晶 `#B9A0EB`、旧金 `#C8AE73`。禁止黑底低对比灰字，禁用频闪和强烈红闪。
- 字体：授权展示衬线用于标题，黑体用于正文，等宽数字用于属性；不使用难读符文替换题目字。
- 素材：原创幻想角色、魔法纹章、远景/中景背景、卡边、非抢眼粒子层；不是现有动漫角色或 IP 风格复制。
- 动画：觉醒入场 300–500 ms、选择反馈 120–180 ms；纹章缓动仅短暂一次；每屏避免多个持续特效，动画以 opacity/transform 为主。
- 结果方向：幻想角色收藏卡 + 有文字标签的倾向图；归一化口径明确，色彩不代表诊断；封面、结果、海报都有“娱乐性格测评，不作为心理诊断”。

### 动物人格匹配：可爱卡通

- 构图：原创 Q 版动物突破画框、错落贴纸、圆角收藏卡；答题选项为清晰大触达块，不能被装饰挤压。
- 色彩：奶油 `#FFF4D9`、森林 `#33594B`、蜜桃 `#F2BAA5`、湖蓝 `#A8CFDB`；深色正文配柔和底色，不用浅色字搭浅背景。
- 字体：授权圆体标题，正文黑体；手写字体只用于短装饰标注，字号与字重保持阅读舒适。
- 素材：原创 Q 版动物（统一线条与比例）、手绘贴纸、边框、纸质纹理；角色差异来自形态和姿态，不只颜色。
- 动画：选择轻弹 150–220 ms、贴纸入场 220–320 ms；反馈一次即结束，不抖动题干、持续跳跃或挡住下一题。
- 结果方向：有收藏欲的动物角色卡，性格短句与生活化描述；海报保持角色主体、短句、品牌署名，信息不过载。

## 素材工作流

`public/assets/themes/<theme>/asset-plan.json` 为 D0 待制作清单：ID、用途、尺寸、风格、生成提示词、透明要求、状态与授权字段。全部标记 pending，没有最终图片或已批准商用声明。角色数量在 D2 的结果原型数量确定后扩展清单；首轮每主题一个代表角色用于视觉验证，不能误称完整角色库。

图片生成工具可用，但 D0 不制作正式插画；D1 授权后先确认角色简报和统一风格，再制作/审核代表素材。工具可用不保证一次生成即可商用交付。若后续不可用，沿用需求清单并采购或委托原创，保持 pending。

原创装饰 CSS/SVG 可直接实现，D0 页面中的圆环、纹章线和贴纸轮廓是构图研究，不代替立绘。AI 图片独立存放，不将 base64 写进组件。建议大型原始素材与参考资料存非公开工作资产区，审核后导出优化版到资源包。

每个最终素材记录作者/生成方式、模型/提示词版本（如适用）、来源、授权证据、审核人/日期、哈希、宽高/格式与焦点裁切。字体单独记录许可证及中文覆盖；人物/动物透明图推荐 WebP/PNG，背景推荐 WebP/AVIF，多分辨率导出。未经许可参考图不得进入商业包。

## 移动、性能与可访问性

正文设计画布 390×844 CSS px，覆盖 320/375/390/430 宽度，必要时自然滚动，不锁死一屏或裁切文案；适配 safe-area。桌面用受控宽度或专用构图，不能只放大手机版。短标题不能牺牲长题、长选项和原型描述。

尊重 `prefers-reduced-motion`；静态状态仍完整表达选中、进度、结果。动效不能承担唯一提示。按钮和交互项有焦点、选中与禁用语义；选项使用可访问单选语义；属性图有文本等价。颜色组合最终必须测量对比度，当前色表是设计输入，不是已验收结论。

D1 初步预算：关键首屏下载 ≤1.5 MB、代表角色优化版 ≤500 KB、装饰不阻塞正文；一屏 ≤1 个短场景动画，避免大面积 blur/filter。在统一设备与网络条件下记录 LCP/CLS/帧表现；不能用开发机桌面感觉替代手机证据。预算可经证据调整并记录决策。
