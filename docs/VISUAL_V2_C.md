# Visual V2-C：藏馆探寻的收敛式体验研究

日期：2026-10-11（Asia/Shanghai）。本轮以 `e144614` 为基线，在既有 `codex/visual-v2-exploration` worktree 中将作者已选择的「藏馆探寻」答题节奏，与 Visual V2-B 的角色揭晓、完整报告和收藏海报收束为同一条研究体验。它仍是独立视觉实验，不替换正式消费者流程、V2-A/A.1/B 比较基线或任何正式领域契约。

## 路由与体验范围

消费者封面为 `/studies/visual-v2-c`，研究入口为 `/studies/visual-v2-c/research`，答题路由为 `/studies/visual-v2-c/question`。确认是答题路由内部状态，不是独立 URL；其后路径为 `/reveal` → `/report` → `/poster`。路由和局部组件使用受审查的本地 asset registry，不从答案、查询参数或 QuizPack 读取任意图片 URL、代码或 HTML。

十二题保留原有题干、选项、选择/取消、返回修改、暂存/恢复、损坏与冲突语义。答题阶段按 `question.id` 位置进入四个中性展厅，每三题一厅：青玉入口以晨光和玉铜制造起念感；暖金书室以灯光与纸面承接观心；雨蓝回廊以雨、窗和竹影放慢节奏；靛夜内藏以更静的暗绢空间收束留记。环境不会随选项变化，也不携带人物、分数、性格线索或未揭晓身份。

确认后才进入固定 synthetic 结果展示。报告不再跳回旧 V2-A.1 页面：它以统一深青/金色视觉完成身份摘要、紧凑人物裁取、题签、五维图谱、匹配依据、优势与留意、相似人物文化以及海报入口。海报继续是展示概念，未实现导出或保存。

结果继续使用已有固定合成李白示例、五维图谱 `88 / 82 / 64 / 46 / 38` 和已有题签 DTO。五项数值不来自当前十二题，不表示人格测量、真实百分位、匹配概率或正式人物结论。新报告只消费 ResultAtlas 和明确的人物展示文本；不消费旧 `HistoricalReportView.dimensions` 的四维倾向或 `rationale`，避免把两套维度混合为同一评分解释。

## 美术与授权边界

V2-C 使用本轮受审查本地候选资源：人物图、四间无人物展厅及必要的缩放衍生尺寸。所有概念图的溯源状态登记在对应 `public/assets/themes/historical/visual-v2-c/manifest.json` 和提示词记录中标为 AI 生成、无参考图或实际输入状态、`pending` 与 `not-approved`。资源登记只说明溯源；不构成商用授权、史实复原、最终角色设定批准或作者审美通过。

报告首屏使用同一 celestial 人物图的局部脸肩裁取，不重新引用旧 V2-A 人像，也不创建第二张“报告专属肖像”。视觉组件必须为加载、缺图和 reduced-motion 保留诚实的可读 fallback；人物图失败时不得伪造结果身份或让文字不可读。

## 资源与性能预算

响应式图只进行等比缩放和WebP编码，不重绘、不调色、不另造角色。默认390px/DPR1选源的四张展厅分别为24,344 / 23,270 / 21,976 / 18,138 B；人物主画67,850 B；报告160px源10,010 B。完整流程所需这六张不同尺寸图合计165,588 B（文件体积，不含HTTP头；相同人物主画在揭晓与海报之间复用浏览器缓存）。960px源供高DPR/桌面选择，人物960源199,972 B。原始大图和历史路径均保留，不用较小衍生图覆盖旧证据。

新字体 `public/assets/fonts/visual-v2-c/serif-600.woff2` 为 Noto Serif SC 600 本地800字符子集，138,168 B；已用字体cmap检查全部声明字符，保留Google Fonts来源CSS、SHA-256与原OFL许可证。获取正确TTF子集后使用本仓库忽略目录内的 fonttools 4.61.1 / brotli 1.2.0 转换，不修改全局配置或产品依赖。正文仍用系统无衬线字；浏览器只请求一份本地标题字体，没有第三方字体连接。`font-display: swap` 保证字体未到时文字仍可读。

固定性能预算（390×844、DPR1、Chromium、本机生产服）：单图传输≤200KiB，字体总传输≤220KiB且≤1请求，首屏总传输≤650KiB，LCP≤2.5s，CLS≤0.1；程序驱动滚动的p95帧间隔≤35ms。采样脚本 `docs/qa/visual-v2-c/performance.mjs` 超预算退出失败，保留各请求大小、LCP候选、位移来源和每个样本；每路由使用3个全新BrowserContext。另跑1轮1.6Mbps/150ms/CPU×4的CDP模拟作为诊断，不冒充移动实机或真实用户数据。
