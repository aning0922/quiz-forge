普通题：点选、再次点击取消、方向键切换、返回修改、未选择阻止前进。选择后180ms以内反馈，不自动跳题、不增加强制等待。12题分为3章×4题；进度同时呈现当前题号与已答数的可访问语义。

暂存：复用 `historical-demo.ts` 题目和验证器；新 controller 在quiz领域模块，主题只消费其接口。A/B使用各自 `quizforge.visual-v2.{direction}.v1`，不覆盖D1-B的key。刷新先呈现恢复入口；清除需要展开“想从头开始”后明确点击。保存失败不显示成功；损坏值不自动清除或覆盖；真实storage事件使选择与确认锁定，读外部进度和采用本页草稿均有显式操作。

身份边界：封面/题目/恢复/确认不接收报告身份，人物图不提前请求。结果fixture仅由显式Server结果研究路由传给展示组件，不进入题目controller；链接关闭预取。确认页说明固定示例不由答案计算，点击“查看合成揭晓”后才导航。独立结果路由可被研究页直接访问；这不是正式鉴权或完成事务。

报告：概览先给一句话和三个关键词；四章节锚点便于跳读，解释依据和文化背景可展开。倾向仅突出/均衡/内敛，无百分比、匹配概率、雷达图或稀有度。长段落16px及以上、1.8左右行高；题目25/24px，普通选项16px，主操作56px；小于16px的字仅为元数据/非正文标记。触控范围至少44px。长题和24px放大自然增高，不定高裁切。

海报为可访问的React/CSS画幅概念，有姓名、称号、短句、关键词、品牌与合成说明。没有导出/保存按钮、分享链接或假二维码，不显示保存成功。实际图片生成/导出属于后续明确授权范围。

## 7. 推荐与作者决策

推荐 **A「入画寻己」作为首款主方向候选**：更贴近低成本、轻投入的趣味测评，封面理解和长报告阅读更直接。B应保留为完整比较对象，它的藏卡结构对揭晓/收藏更有吸引力，但更依赖成套人物美术质量。此结论为设计判断，不是A/B转化测试。

请作者在实际体验后决定：

1. 主体验选择A还是B；是否只吸收另一方向的某个已验证部件，而不把两套结构无原则拼接。
2. 题目推进采用当前“选择后下一题”的稳妥方式，或后续另试自动前进；本轮保留可修改、可取消和无强制等待。
3. 最终人物美术的精细程度、年龄/服饰方向、首发角色数量，以及是否批准当前AI概念进入进一步打磨。
4. 海报更偏编辑纪念画（A）还是完整角色藏卡（B），并在后续阶段另行授权导出与保存。
