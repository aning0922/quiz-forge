# Visual V2-A.1 展示与未来评分契约

日期：2026-10-11。基线 `eb028a59c70e8b735362335bf16d9941f88a5654`，沿用 `codex/visual-v2-exploration`，更新 Draft PR #4。此文先于接口改动记录边界；以下是内部视觉提案，**不冻结正式 QuizPack Schema，不创建业务表或迁移**。

## 本轮展示输入

只读 `ResultAtlasView` 标明 `kind: synthetic`，由固定fixture传入4–7个维度。每项包含 `dimensionId`、`label`、`normalizedScore`、`interpretation`、`scaleDescription`、`displayOrder`、两端倾向名称。只接受有限的0–100数值；显示原数值，不把分数当百分位、匹配概率或科学准确率。排序仅按displayOrder；拒绝重复ID/顺序、缺字段与越界值，不静默截断或把坏数据补成0。该保护仅覆盖内部图谱展示，不是包导入验证器。

A/B共用88、82、64、46、38，自主探索/创造表达/关系共鸣/审慎规划/稳健执行。两端描述明确较低与较高的含义，分数不代表优劣、能力或价值。人物仍是独立固定合成李白；图谱、匹配解释、题签均不来源于当前12题，不建立评分链路。

人物专属文案单独进入只读视觉文案DTO：报告标题/一句话摘要、角色印记/英文题名、揭晓引语、匹配示意（引用dimensionId）、优势短板标题、海报短句与2–3个明确指定的维度标签。身份/时代/肖像ID、优势/短板正文、相似人物与文化仍通过现有只读报告视图提供。UI通用章名、操作文字、免责声明、框线和配色属于模板。原D1-A.1报告接口与fixture不改写。

## 性情题签提案

独立只读判别联合区分真实古诗 `classical` 与 `original`：共同字段为ID、两行正文、简短解读、精简海报行。古诗必须有作者、作品、来源标题/URL、核对日期；原创必须有明确原创拟古署名，不能填写古人作者或虚构作品出处。当前组件可省略题签；海报只用一行及署名，不增加整块诗文挤占人物。

候选配置将同一人物原型映射到多组题签及相关维度ID/叙事意图。本轮只固定默认候选，研究入口可以显式切换候选；没有分数阈值匹配、随机选择、AI实时生成或联网检索服务。解读是合成性情与文化意象之间的编辑说明，不编造用户经历。

真实示例使用李白《行路难·其一》末二句；以南通大学诗文正文核对，中央纪委国家监委网站检索片段作交叉参考（其正文抓取超时，不作主证据）。只取古代公版诗句，不复制现代鉴赏文、照片或网页设计。现代短解读为项目自行撰写。出处核对不等于本项目人物图片获商用批准。

## 后续确定性评分（仅规划）

1. **维度可配置**：每个商品版本固定维度ID、语义、正反向、题目/选项权重、必答/跳题规则。图谱4–7项是本视觉配方范围，不限制未来所有商品的领域模型。
2. **理论上下界**：每项维度先在合法可达答卷集合上确定L/U；有跳题、互斥项或条件权重时不能把不可同时出现的极值相加。明确缺失答案处理，正式完成前拒绝不完整输入。L/U须版本化并可复核。
3. **归一化提案**：正向采用 `100 × (raw − L) / (U − L)`，反向在定义中显式翻转。L=U、规则不可达或raw越界均属于配置/评分错误，不自动补50或截断。精度、舍入模式和逆向规则需在评分版本中固定；当前展示层不执行此公式。
4. **追溯**：报告保留评分规则版本/摘要、维度定义版本、原始分值/理论界限/归一化值与必要贡献证据引用；答题原文和Key不进入公开分享DTO。当前fixture不伪造规则ID或贡献来源。
5. **人物匹配**：使用同一维度向量与版本化人物原型定义；未来另审权重、距离/相似度、平局优先级及不适用维度处理。当前没有选定匹配公式，不把最大维度直接等同人物，也不把任何距离显示成概率。
6. **确定性与封存**：相同答案及完整商品/评分版本必须产生相同分数、人物、解释依据与题签选择。完成权威由未来服务事务/唯一约束授予，并保存不可变ReportSnapshot。历史查看只读快照，不能因新规则重新计算。
7. **AI边界**：AI仅增强已计算/验证的文案，无权修改数值、维度顺序、人物或规则证据；输出校验、幂等、失败回退与封存按现有REPORT_MODES提案。正式评分不依赖AI。

## 后续题签选择（仅规划）

商品版本固定候选集合、人物适用范围、维度条件与优先级；先限定已算出的人物原型，再按同一份快照维度选择候选。多个候选同优先级使用稳定ID决胜，不使用时间或随机数。无满足条件且有审批的候选则省略题签，不补造古诗。保存选中题签ID/文本版本/来源与规则证据到不可变快照；后续更换候选或外部链接失效不改历史报告。原创与引文的来源类型不能被AI变更。
