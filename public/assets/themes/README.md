# Theme Asset Packs

D0 只有 `historical/`、`sins/`、`animals/` 的 `asset-plan.json`。这些是素材需求清单，不是批准的资源包；全部 pending，无实际角色图片、字体或商用许可证据。

AI 图片/委托原稿与组件分离。每主题先制作一个代表角色验证 D1，后续结果原型数量确定后扩充。正式发布时需要 approved manifest、不可变路径、内容哈希、尺寸和商用来源审核。

清单包括生成提示词、用途/尺寸、透明要求和待填写的授权字段。文字由程序排版，图片中不生成标题/题目。D0 CSS 几何装饰仅供构图预研，不代替角色立绘。
